# Student Enrollment & Lead Analysis Dashboard

An Excel-based data analytics project that explores student leads, enrollment trends, counsellor performance, and lead source conversion rates. The goal is to understand where leads drop off and identify opportunities to improve admissions.

## Project Overview

An education institute receives leads through different channels but needs better insights into which leads convert into enrolled students. This project uses data cleaning, Excel formulas, KPI analysis, and interactive charts to turn raw data into useful business insights.

## Tools Used

- Microsoft Excel
- Excel Formulas and Functions
- Data Cleaning
- Charts and Dashboard Design
- Google Sheets and Looker Studio (reporting tools)

## Key Features

- Student enrollment and conversion rate analysis
- Admissions funnel and monthly trend analysis
- Counsellor-wise performance comparison
- Lead source and course performance analysis
- Data cleaning and duplicate removal
- Pending follow-up tracking

## Key Insights

- Total leads: **1,200**
- Enrolled students: **180**
- Overall conversion rate: **15%**
- Referral leads achieved the highest conversion rate at **24.2%**.
- Sneha Reddy had the highest counsellor conversion rate at **22.1%**.
- The largest funnel drop occurred between the Interested and Applied stages.

## Data Cleaning

The raw dataset contained 1,248 rows. After cleaning, 1,200 records remained.

Cleaning steps included:
- Removing duplicate lead IDs
- Standardizing city, lead source, and status values
- Fixing extra spaces and inconsistent text formatting
- Handling missing values
- Creating helper columns for analysis

## Business Recommendations

- Focus on referral campaigns to improve lead conversion.
- Follow up with leads who remain at the Interested stage.
- Review counsellor performance and improve lead distribution.
